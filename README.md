# SMS Spam Filter

Case study for the IU module DLBDSME01 (Model Engineering), Task 3. It builds a spam filter for a
public customer-feedback message channel. The filter is adjustable through three spam-risk levels,
from low risk (very restrictive) to high risk (not restrictive): a message scoring below the
threshold of the selected level is displayed immediately, and every other message is moved to a
review folder for further analysis. The whole analysis follows the CRISP-DM phases and lives in a
single notebook.

## Repository structure

```
data/raw/         Raw SMS Spam Collection file, unmodified
models/           Trained model (joblib) and model card (JSON)
notebooks/        spam_filter.ipynb, the complete analysis
results/figures/  Figures generated by the notebook (PNG)
results/tables/   Result tables generated by the notebook (CSV)
results/logs/     Run log written by the notebook
```

## Reproducing the results

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m jupyter lab
```

Then open `notebooks/spam_filter.ipynb` and run **Kernel > Restart Kernel and Run All Cells**. The
random seed is fixed at 42 for every split and model, so the reported numbers reproduce exactly. The
recorded run used Python 3.12.3 with the versions pinned in `requirements.txt`, among them
scikit-learn 1.9.1, pandas 3.0.5, numpy 2.5.3 and matplotlib 3.11.2.

## Main results

The selected model is TF-IDF + Logistic Regression, trained on 4,128 messages (514 spam) and
evaluated once on 1,032 held-out test messages (128 spam). On the test set it reaches an average
precision of 0.961 and a ROC AUC of 0.993; at the default threshold of 0.5, accuracy is 0.96,
precision 0.968, recall 0.703 and F1 0.814.

| Risk level | Threshold | Spam caught | Legitimate held back |
|---|---|---|---|
| Low risk (very restrictive) | 0.073 | 128 of 128 | 171 of 904 |
| Medium risk | 0.245 | 118 of 128 | 11 of 904 |
| High risk (not restrictive) | 0.395 | 101 of 128 | 4 of 904 |

## Outputs

model card to `models/spam_filter.joblib` and `models/spam_filter_card.json`.
